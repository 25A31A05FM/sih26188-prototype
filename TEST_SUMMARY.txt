================================================================================
TEST CASES BY DOCUMENT TYPE
================================================================================

TEST CASE 1: Good Quality Document
├─ Image: Clear, well-lit, all text visible
├─ Fields: All present and valid
├─ Expiry: Future date (not expired)
└─ Expected Result:
   - risk_score: 0-15
   - verdict: low_risk
   - reasons: [] (empty or minimal)

TEST CASE 2: Expired Document
├─ Image: Clear
├─ Expiry: Past date
└─ Expected Result:
   - risk_score: >= 30
   - verdict: high_risk or medium_risk
   - reasons: ["Document is expired"]

TEST CASE 3: Blurry Document
├─ Image: Intentionally blurred
├─ Focus: Poor
└─ Expected Result:
   - tamper_score: >= 15
   - reasons: ["Image is very blurry"]

TEST CASE 4: Low Resolution
├─ Image: < 300x300 pixels
├─ Quality: Pixelated
└─ Expected Result:
   - tamper_score: >= 10
   - reasons: ["Low-resolution image"]

TEST CASE 5: Heavily Compressed
├─ Image: Over-compressed JPG
├─ Colors: Reduced palette
└─ Expected Result:
   - tamper_score: >= 10
   - reasons: ["Low pixel variation, possibly compressed or edited"]

TEST CASE 6: Missing Fields
├─ Image: No date, no number, etc.
├─ OCR: Fails to extract
└─ Expected Result:
   - rule_score: >= 50
   - reasons: ["Missing name", "Missing dob", etc.]

TEST CASE 7: Face Match (Same Person)
├─ Document photo: Clear face
├─ Selfie: Same person
└─ Expected Result:
   - verified: true
   - distance: < 0.6

TEST CASE 8: Face Mismatch (Different Person)
├─ Document photo: One person
├─ Selfie: Different person
└─ Expected Result:
   - verified: false
   - distance: > 0.6
