## ❓ FAQ

**Q: Can I submit late?**
A: Check SIH website for extensions. Email contact@sih.gov.in immediately.

**Q: Do I need to be in college?**
A: Yes, typically. Check official guidelines for eligibility.

**Q: How many team members?**
A: Usually 4-6 members. Check guidelines.

**Q: Is code review before submission?**
A: No, submit before deadline. No review before submission.

**Q: Can I update code after submission?**
A: Usually no. Make sure everything works before submitting.

**Q: What if my GitHub link breaks?**
A: Keep repository public and alive. They'll access it after submission.

**Q: Do I need professional video?**
A: No, just clear screen recording with audio. OBS Studio is fine.
